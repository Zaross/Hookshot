What you get

Features

Everything you need to bridge your repositories to Discord — nothing you don't.

🔗

GitHub & GitLab

Both platforms work out of the box. HMAC signature verification for GitHub, secret token validation for GitLab — with constant-time comparison.

🎨

Custom Embed Templates

Design your Discord embeds with a live preview builder. Control title, description, color, footer, author, thumbnail, and more via template variables.

🔁

Automatic Retry Queue

Discord 429 / 5xx responses trigger exponential backoff retries (30 s → 5 min, up to 5 attempts). Inspect and manage the queue from the admin panel.

🔐

TOTP Two-Factor Auth

Protect admin accounts with TOTP (Google Authenticator, Bitwarden, Authy). Includes 8 one-time backup codes for recovery, SHA-256 hashed at rest.

🛡️

Brute-Force Protection

Per-account lockout after 5 failed login attempts. Per-IP rate limiting (20 attempts / 15 min) persisted in SQLite — limits survive server restarts.

📊

Real-Time Dashboard

Stats and live log feed update instantly via Server-Sent Events. No refresh needed — new webhook events appear with a pulsing Live indicator.

📈

Prometheus Metrics

Scrape /metrics with any Prometheus-compatible collector. Tracks webhook counts by status, queue depth, repositories, and users.

⚡

Settings Cache

API keys are held in an in-memory RwLock cache — zero DB roundtrips per request. Cache is invalidated atomically when settings are updated.

📖

Swagger UI

Every endpoint is documented with utoipa annotations. Browse and try all API endpoints interactively at /api/docs.

🌿

Branch & Keyword Filters

Per-repository allowed branch list and commit keyword filter — silently drop pushes you don't care about. Dependabot is always filtered.

🗃️

SQLite + Auto-Maintenance

Zero-dependency embedded database. Weekly VACUUM + ANALYZE keeps file size minimal and query planner accurate automatically.

📦

~20 MB Docker Image

Statically compiled Rust binary on Alpine Linux. No external runtime dependencies, no JVM, no interpreter.

Get running in 60 seconds

Quick Start

Three commands and you're live.

Shell
git clone https://github.com/your-username/hookshot.git
cd hookshot
docker compose up -d
Default credentials: Open http://localhost:8080 and sign in with admin / admin123. You will be prompted to change the password on first login.

Connect a Repository

1

Create a Repository in Hookshot

Go to the admin panel → Repositories → Add. Enter your repo's full name, choose GitHub or GitLab, and paste your Discord webhook URL. Hookshot generates a unique token and secret automatically.

2

Add the Webhook on GitHub / GitLab

In your repository's webhook settings, set the payload URL to https://your-domain.com/webhook/<token>, set content type to application/json, and enter the secret. Subscribe to push events only.

3

Push Something

Push a commit. Within seconds a Discord embed appears in your channel. Use the Test Send button in Hookshot to fire a test without a real push.

GitHub Setup

  1. Repository → Settings → Webhooks → Add webhook
  2. Payload URL: https://your-domain.com/webhook/<token>
  3. Content type: application/json
  4. Secret: paste from Hookshot repository page
  5. Select Just the push event

GitLab Setup

  1. Project → Settings → Webhooks
  2. URL: https://your-domain.com/webhook/<token>
  3. Secret token: paste from Hookshot repository page
  4. Enable Push events
  5. Click Add webhook

Authentication: Protected endpoints require a Bearer <token> header. Obtain a token via POST /api/auth/login. Admin-only endpoints additionally require the admin role.

Security Model

Security

Hookshot is designed with defence-in-depth for self-hosted production use.

🔑

Passwords

Argon2id hashing with per-user random salts. Minimum 8 characters enforced. Forced change on first login.

🔢

TOTP 2FA + Backup Codes

RFC 6238 TOTP. 8 backup codes are generated at enable time, SHA-256 hashed, and consumed on use. One code per login attempt.

🚫

Rate Limiting

Login and TOTP: 20 attempts / 15 min per IP, persisted in SQLite. Webhooks: 120 / 60 s per IP in-memory. All return proper Retry-After and X-RateLimit-* headers.

🔏

Signature Verification

GitHub webhooks: HMAC-SHA256 via x-hub-signature-256. GitLab: shared secret via x-gitlab-token. Both use constant-time byte comparison.

🎫

JWT Sessions

HS256 JWTs with a randomly generated secret stored in the database. Logout blacklists the JTI. Per-session revocation supported. Expired blacklist entries are purged daily.

🛡️

Security Headers

X-Content-Type-Options: nosniff, X-Frame-Options: DENY, X-XSS-Protection: 1; mode=block, Referrer-Policy: strict-origin-when-cross-origin.
